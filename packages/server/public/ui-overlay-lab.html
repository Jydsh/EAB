Toast / Snackbar 轻提示

看一眼就走的反馈：自动消失、悬停暂停、可带撤销。错误提示不用自动消失来逃避用户。

不阻塞页面

验收点：鼠标移上去计时暂停；按 Tab 聚焦关闭按钮也会暂停；点“撤销”后提示关闭并执行动作； 错误提示停留更久且带关闭按钮。连续点五次最多保留 3 条，不堆满屏幕。

Popconfirm 气泡确认框

锚在触发按钮旁边，适合行内低/中风险操作。点外面取消，Esc 取消，默认焦点在“取消”。

不打断整页
场景 文案 风险 动作
移除角色成员 只移除这个角色，不影响其他角色 中风险 · 可恢复
删除测试用例 只删用例，不影响历史记录 低风险 · 行内删除
发布流程 发布后新版本立即生效 需确认 · 可撤销版本
异步失败 模拟接口失败，确认框留在原地显示原因 错误可重试
