    用企业身份扫码登录

    改用授权页登录
    飞 飞书扫码登录

    这家公司已绑定飞书。飞书扫码登录链路还在接入中，先切到「账号密码」登录。

    还没配置企业扫码登录

    由公司管理员在控制台「渠道」里绑定钉钉或飞书后，这里会自动出现扫码入口。

    现在可以直接用账号密码登录。

    二维码由钉钉官方组件渲染，手机不需要访问本机地址；扫码只用于身份登录。

    账号密码登录

    用工号、邮箱或手机号登录。账号只能由本人登录，密码校验在服务端完成。

    浏览器会话 7 天有效；账号停用后立即失效。
