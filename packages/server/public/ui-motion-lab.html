Scrolltelling / Full Pattern

滚动不是特效，
是把论证顺序排好。

左侧三步随滚动点亮，右侧画面短暂钉住。它适合官网、产品故事和登录后的首次引导， 不适合工作台里的表格与表单——那里的滚动必须始终服从操作。

01 / 问题

先让人看见“为什么要变”

企业里最贵的不是动画，是沟通成本。一个状态如果只能靠文字解释，就会在培训、交接和客服里反复消耗。

02 / 证据

再用层级说明“先看哪里”

动效不负责制造注意力，它负责把已经存在的层级显影：谁在运行、哪里出错、哪一步需要确认。

03 / 行动

最后把下一步交回给人

所有动效结束时，界面必须比开始时更清楚：能点的更明确，不能点的有原因，正在等的有进度。

EAB / STORY01 — 问题

动效不是装饰，是界面的解释层。

当状态变化没有被看见，用户就会用刷新、重复点击和猜测来补足理解。

12%
Guardrails

三条底线，
决定“高级”还是“花哨”。

规范的价值不在于多，而在于每次评审都能用同一把尺子。下面三条是 EAB 的硬约束。

01 / TIME

100–200ms 做反馈，200–300ms 做转场

按钮、开关、悬停要快；面板、弹窗、抽屉可以稍慢。超过 300ms 的操作反馈会让人怀疑“是不是没点上”。

02 / PERFORMANCE

只动 transform 和 opacity

不改 width、height、top、left，不触发布局重排。大量列表、表格和长文默认不加动效，优先保证滚动与输入。

03 / ACCESS

尊重“减少动态效果”

系统开启后，关闭非必要动画；信息不能依赖动效才能读到。键盘焦点、触控目标和对比度始终优先于视觉效果。

MOTION BRIEF / 一句话描述

“给运行中的 Agent 卡片加 Border Beam，2.8 秒循环，只提示运行状态；同时用 Ease Out 让按钮按压在 120ms 内完成。不要改布局，开启减少动态效果时全部关闭。”
