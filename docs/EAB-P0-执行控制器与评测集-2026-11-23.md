# EAB P0：执行控制器与评测集（2026-11-23）

本轮接的是审计文档里的 **AGT-03 回合执行控制器** 和 **AGT-06 评测集 v0 + 发版闸门**，目标是把 AGT-01/AGT-02 两道门禁变成可回归的验收项，而不是继续加业务功能。

## 1. AGT-03 执行控制器

新增 `packages/server/src/execution-controller.ts`，只做确定性预算，不调用模型裁判：

| 预算 | 默认值 | 配置项 | 行为 |
| --- | --- | --- | --- |
| 普通回合总时长 | 180 秒 | `chatTurnTimeoutMs` | 到线停止，不再开新一轮 |
| 工程/项目回合总时长 | 30 分钟 | `chatProjectTurnTimeoutMs` | 同上，给本地工程任务留时间 |
| 单回合工具调用次数 | 48 次 | `chatTurnMaxToolCalls` | 到线停止 |
| 单轮思考字数 | 4000 字 | `chatTurnMaxReasoningChars` | 超出部分不再进入上下文和前端 |
| 模型轮次 | 沿用 `maxRounds` | `maxRounds` / `agentChildMaxRounds` | 到线停止 |

超预算时统一输出：

> 【执行预算】已查到部分结果（完成 N 次工具调用），但本轮执行已停止。未完成原因：……。为避免继续空转，先停在这里；可以缩小查询范围、拆成更小的问题再试。

命中预算后跳过交付门禁和“补一次收尾模型调用”，避免一边说“已停止”一边继续烧 token。

工具轮次用满后仍会补一次“不暴露工具”的收尾调用；这条收尾正文同样要过数据交付门禁，门禁不通过时只输出“最终答案没有通过数字核对”，不会把未核对合计直接流给用户。

## 2. AGT-06 评测集 v0

基准集：`evals/agent-baseline.v0.json`，30 条：

- 12 条答案事实门禁题：合计、条数、日均、占比、日期/版本号排除、表格行、伪造数字、连续拦截、非数据问题。
- 8 条条件绑定题：人名、文档标题、编号、部门名/时间词排除、动词后人名。
- 10 条执行预算题：轮次、时长、工具次数、思考截断、预算提示。

跑分器：`scripts/eval-agent.ts`，直接调用生产用的三个纯函数模块，不启服务、不连真实模型，保证每次发版可重复。

```powershell
pnpm eval:agent
pnpm verify:release
```

`verify:release` = `typecheck` + 全量单测 + 评测闸门。Windows 上全量 vitest 已限制为单 worker（`--minWorkers=1 --maxWorkers=1`），`tsc` 使用 4GB 堆。2 个及以上 worker 在部分机器上仍会因进程资源耗尽崩溃，单 worker 用时长一些但结果稳定。

### 当前基线

```text
用例 30/30 通过 · 完成率 100.0%
取数成功率 100.0% · 数字一致率 100.0% · 无依据数字 0
工具轮次 P95 3 · 单轮思考 P95 2000 字
发版闸门通过。
```

闸门阈值：

- 完成率 ≥ 95%
- 数字一致率 ≥ 95%
- 无依据数字 = 0
- 工具轮次 P95 ≤ 3
- 单轮思考 P95 ≤ 2000 字

## 3. 验证记录

- 首轮 `pnpm verify:release` 通过：230 个测试文件 / 1408 条用例，评测 30/30，退出码 0。
- 追加“工具轮次用满后的收尾正文也要过数字门禁”用例后，门禁相关 5 个测试文件 / 44 条用例串行通过，评测 30/30 通过。
- 当前主机提交内存已接近上限（约 85.2 / 86.1 GB），`tsc` 与多 worker vitest 会报 `Fatal process out of memory: Zone` / `EPIPE`；全量复跑需要重启主机释放提交内存后再执行 `pnpm verify:release`。

## 4. 边界与后续

- 本轮评测是**门禁级确定性回归**，不是“真实模型 + 真实插件”的端到端跑分；下一步 AGT-06 v1 应接真实会话和真实插件样本。
- 思考预算是“截断进入上下文/前端的字符”，不是在中途强杀供应商流；模型侧总时长仍由 `modelTimeoutMs` 和回合墙钟兜底。
- 总时长在“每轮开始 / 模型返回 / 工具执行后”检查，不是毫秒级硬中断；工具本身仍受 `pluginToolTimeoutMs` / `mcpToolTimeoutMs` 约束。
- 版本号未变更；发布前按用户确认的 `v年月日.序号` 规则处理。
