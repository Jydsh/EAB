## 2. 目标与非目标

### 目标

1. 每个高频页面都有可理解的 `加载 / 空 / 错误 / 无权限 / 禁用` 状态。
2. 全站视觉密度、字阶、间距、表格行高和边框层级有统一 token。
3. 后台表格支持真实工作流：筛选、分页、列优先级、批量操作、行内操作收口。
4. 员工端在桌面、窄屏和平板上都能完成“对话 + 引用 + 文件预览”。
5. AI 回答固定为“思考与工具 → 结论 → 来源/附件 → 可执行操作”，错误可重试。
6. 键盘、焦点返回、读屏名称和 reduced-motion 达到可交付底线。

### 非目标

- 不重写路由、权限模型、数据层或 Agent 运行时。
- 不为“高级感”大面积加入场动画、渐变和装饰卡片。
- 不一次性重做整个后台；每批只改一个设计轴。
- 不在未确认前升级产品正式版本号，不自动 commit/push。

## 3. 统一设计规则

### 状态

- **加载**：表格页用 3–5 行骨架；非表格页用一行状态文案，不铺满整屏。
- **空**：标题 + 一句原因 + 一个主行动；没有合适行动时只保留“刷新/清除筛选”。
- **错误**：行内状态块，保留具体错误摘要和 `重试`；不把网络错误写成权限拒绝。
- **无权限**：说明当前身份缺少什么，保留错误码/traceId，不提供无效重试。
- **禁用**：说明为什么不可用，以及恢复条件。

### 信息层级

- 一个面板只保留一个主行动；次操作收进 `⋯` 或更多菜单。
- 表格首屏优先展示“对象、状态、最近时间、主操作”；低频列可隐藏。
- 不在卡片里再套一层卡片；分组优先用标题、分隔线和留白。
- 状态颜色只做辅助，必须同时有文字。

### 排版与密度

- 字号层级：12 / 13 / 14 / 16 / 20。
- 间距尺度：4 / 8 / 12 / 16 / 24。
- 后台表格行高基准 44px；紧凑表 38px，仅用于审计/日志。
- 边框层级：页面分区 1px，卡片内部不再重复描边。

### 交互与动效

- 常规反馈 160ms，面板进入 240ms；首屏内容不依赖入场动画。
- **输入类控件（`input` / `textarea` / `select`）聚焦只改变边框颜色，不绘制 `outline`，也不加外圈 `box-shadow`；按钮、链接、复选框等仍保留键盘 `:focus-visible` 焦点环。** 输入框的深色外环不再作为设计语言。
- 关闭浮层/分屏后焦点回到触发点；触发点消失时回到输入框或列表首项。
- 所有 hover 反馈都有键盘等价；触控目标不小于 40px，优先 44px。
- `prefers-reduced-motion` 下移除位移动画，保留即时状态变化。

每批完成必须同时满足：

1. 真实浏览器从产品入口完成目标动作，而不是只查 DOM。
2. 至少覆盖一个正向状态和一个失败/空状态。
3. 相关控制台和请求无新增错误。
4. 受影响的静态检查通过；涉及交互的批次补真实键盘/触控验证。
5. 文档记录实际改动、未验证项和截图路径。
6. 不把历史未提交改动归为本批成果。

## 7. 风险与回退

- **共享状态块影响面过大**：先只在三个页面试点，使用新类名，不直接改 `.empty` 全局样式。
- **错误分类误判**：以 `status` 和错误码为主，不用文案猜权限。
- **表格空态撑高**：空态块限制内边距和行数，移动端单独收紧。
- **焦点修复引入滚动**：使用 `focus({ preventScroll: true })`，必要时只恢复可见触发点。
- **动效影响首屏**：首屏内容不做 reveal；新增动效必须有 reduced-motion 分支。
