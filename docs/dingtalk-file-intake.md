# 钉钉私聊文件：落个人云空间并反问

## 口径

钉钉机器人私聊收到 `msgtype: "file"`（或 `richText` 里的 `file` 项）时：

1. 用 `content.downloadCode` 换钉钉临时下载链接，下载文件；
2. 落进当前员工的个人云空间（`workspace_files.scope_type = 'user'`），
   与网页「上传文件」共用同一套目录、配额和元数据；
3. 在对话里写入一条用户消息和一条 EAB 回复，回复明确说明保存位置，并反问：
   「你想让我对这个文件做什么？比如：总结要点、提取表格、改写格式、找出问题。」

文件不会直接送给模型：先保存、先问意图；用户下一句说明要做什么后，模型从会话历史里拿到文件路径再处理。

## 限制

- 单文件上限取个人空间策略里的 `fileLimitBytes`（默认 50 MB）；下载阶段也按 50 MB 预检。
- 同名文件不覆盖，自动追加 ` (1)`、` (2)`。
- 文件类型按响应 `content-type` 或扩展名推断；二进制文件仍可在网页侧下载。
- 钉钉 `downloadCode` 只在真实消息里出现，自动化无法伪造；真实下载链路的验证需要从钉钉客户端发一次文件。
- 保存后如果个人云空间达到预警线（75% 起），文件回执会自动追加「容量提醒」；详见 `docs/workspace-capacity.md`。
