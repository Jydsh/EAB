# EAB v2026.11.16 发布说明

发布日期：2026-11-16
版本类型：稳定性修复
发布基线：`main`

## 版本概述

`v2026.11.16` 重点修复局域网登录页反复重载的问题，并补齐「一键升级」的完整性校验、数据备份、健康检查和失败回滚。该版本同时带入当前 `main` 上已完成的渠道卡片、可选后端自动接入和启动层容错等改动。

## 主要修复

### 1. 登录页无限重载

- 登录页上的后台请求返回 401 时，不再触发 `location.replace('/chat?login=1')`，避免登录页反复刷新。
- 权限角标改为登录成功、拿到 `state.me` 之后再拉取；登录前不再请求 `/api/permissions/requests`。
- 启动层和页面初始化异常时直接放行页面，避免覆盖层长期停留在「正在恢复会话…」。
- 更新 `chat.js` / `chat.html` 缓存版本，部署后不会继续命中旧脚本。

### 2. 一键升级完整性

- Release 资产选择增加源码包评分和排除规则，避免误选桌面安装包或校验文件。
- 下载源码包后校验 SHA-256，摘要不匹配立即中止。
- 增加源码完整性检查，缺少 `packages/server/src/main.ts`、`chat.html`、各 workspace 的 `package.json`、`eab.mjs`、`pnpm-lock.yaml` 等关键文件时拒绝替换。
- 替换前等待 chat 端口释放，避免在旧服务仍在运行时覆盖代码。
- 备份代码，并备份 `eab.db`、WAL/SHM、`secrets.json`、`console-settings.json` 和管理员凭据。
- 依赖安装改为 `pnpm install --frozen-lockfile`。
- 更新后等待 `/api/health` 返回目标版本；45 秒未恢复健康则自动回滚代码、数据库和依赖，并重新启动旧版本。
- 控制台一键更新后轮询健康状态，成功自动刷新；2 分钟未确认完成则提示查看 `.eab-dev/updates/last-update.log`。
- 更新器扫描多目录源码 zip，兼容 `EAB-<version>/` 和直接解压到根目录两种结构。

## 升级提示

- 使用控制台「版本更新」或 `eab update --apply` 升级到 `v2026.11.16`。
- 更新前会校验 Release 源码包 SHA-256，并在停止服务后备份运行数据。
- 如果新版本健康检查失败，更新器会尝试恢复更新前的代码和数据库；若端口仍被占用，会跳过自动回滚，避免覆盖运行中的数据。
- `v2026.11.15` 的 Release 资产是修复前构建的，不包含本轮登录修复和升级器改进；局域网部署需要升级到 `v2026.11.16` 才能获得完整修复。

## 数据库迁移

本版本未新增数据库迁移，沿用现有 SQLite 结构与迁移链。
