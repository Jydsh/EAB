# EAB v2026.11.27 发布说明

发布日期：2026-11-28
版本类型：功能与体验版本（定时任务闭环、桌面终端、下载中心历史版本）
发布基线：`main`

## 版本概述

`v2026.11.27` 重点补齐定时任务从创建、编辑、执行到多通道回推的完整闭环，并把桌面端右侧工作台扩展为本机 PowerShell 终端。员工端同时完成侧栏响应式、滚动条、窄屏表单和分界线等一批体验收口。

## 定时任务

- 定时任务支持编辑、保存后保持原状态、结束后重新启用，以及物理删除；运行中的任务拒绝编辑和删除，避免调度器按旧规则继续执行。
- 删除会同时清理 `user_schedules`、`schedule_runs` 和 `schedule_events`，对话内容和已发送的钉钉消息保留。
- 单次任务已过期时在输入阶段直接提示“不会执行”，并在创建、编辑接口双重拦截，不再静默生成永不触发的任务。
- 定时任务改为真正的流式回复：网页端按 token 输出正文和思考过程，工具面板实时更新；刷新后仍保留 `reasoning`、`toolCalls` 和思考耗时。
- 钉钉通知先建 A2UI 流式卡、边执行边更新、结束时同一张卡收口，并登记 `channel_turns`，思考与工具面板可以反查会话。
- 间隔任务从“只能按分钟”扩展为秒、分钟、小时、天、月、年六种单位；秒级最低 30 秒，月/年按本地日历推进并处理月末、闰日。
- 每日/每周/单次时间改用自定义连续双列选择器，小时和分钟不再出现原生弹层的空档；单次任务拆成日期 + 时间，隐藏域仍提交原有格式。
- “结果回推到”改为可搜索组合框：输入即过滤对话标题，不再单独出现搜索框；隐藏 select 仍是表单真实值，清空会回到“新建对话”。
- 创建任务按钮增加成功对勾和轻弹反馈，按钮宽度不跳动；600ms 内保持禁用，避免重复提交。
- 四个统计数字改为旧值向上移出、新值从下方滚入，固定 `3ch` 宽度并使用等宽数字，`9 → 10` 不再横向抖动。

## 桌面客户端

- 新增本机 PowerShell 终端标签：独立会话、UTF-8 输入输出、命令历史、清屏、复制、重启和关闭；窗口关闭或应用退出时按进程树清理，避免残留进程。
- 终端只在 Electron 桌面宿主出现，Web 端不渲染入口；输入焦点只改边框色，不画 outline。
- 下载中心改为版本档案：同时列出历史安装包和便携包，`setup?version=`、`portable?version=` 可独立下载；构建时保留带版本号的便携 zip 副本。
- 桌面端与服务端版本统一由根 `package.json` 驱动，安装包、`/api/health`、更新清单和 Release 使用同一个版本号。

## 员工端体验

- 侧栏紧凑断点从 `1120px` 调整为 `960px`：`961–1216px` 固定 264px 侧栏，`≤960px` 使用 288px 覆盖式抽屉，修复收起后左侧残留 304px 空白。
- 定时任务页在 `≤900px` 单列时两块内容改为 `flex: 0 0 auto`，表单不再压扁并盖住任务卡片，滚动统一交给主区域。
- 全站滚动条隐藏但保留滚轮、触控板和键盘滚动，不再用 `overflow: hidden` 禁用滚动。
- 对话与右侧工作台分界线保持 1px 细线，中央胶囊改为仅鼠标悬停、拖拽或键盘聚焦时显示，默认不再常驻。

## 图表与渠道

- 定时任务按投递渠道注入图表清单：网页 17 种，钉钉只保留 `pie / bar / horizontalBar / line / scatter / stackedBar / groupedBar` 7 种原生类型。
- 钉钉提示词不再推荐环形图、面积图、雷达图等会被丢弃或变形的类型，历史已发送卡片不回溯改写。
