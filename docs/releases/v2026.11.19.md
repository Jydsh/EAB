# EAB v2026.11.19 发布说明

发布日期：2026-11-19
版本类型：模型路由、知识库解析、权限配置与体验版本
发布基线：`main`

## 版本概述

`v2026.11.19` 把自动选模从“按优先级 / 工具能力”改为“按真实回复速度”，并补齐思考档位按模型能力配置、知识库表格结构保留、角色页可用工具双向同步和后台表单勾选体验。

本版新增 1 个数据库迁移，服务启动时自动执行；升级不覆盖 `.eab-dev` 运行数据。

## 主要变化

### 1. 自动选模按真实回复速度

- 钉钉自动回复和网页自动模式统一读取 `chat_messages.meta_json` 中的真实样本：首字延迟 `timing.ttftMs` + 生成速度 `tokens.completion / genMs`。
- 综合排序为 `预计回复耗时 = ttftMs + 256 / tokensPerSecond × 1000`，升序选最快模型；**速度优先于 `priority` 和工具能力**。
- 每个模型取最近 20 条、最近 30 天的真实回答，`ttftMs` 与 tok/s 都取中位数；同一公司缓存 15 秒，新回答落库后立即失效。
- 上游没有返回 usage（`completion=0`）时，用正文 + 推理文本估算 token，避免把这类模型误判成 0 tok/s。
- 样本缺失、过期或读取失败时，才回落到工具模型 / 最近成功模型 / `priority` 的冷启动顺序。
- 显式 `/model`、会话已保存模型、`chat.default` / `chat.vision` 用途路由仍然优先；**Agent 团队仍由 `agent.model_choice` 的 SystemOne 决策模型分配**，不按速度改。
- 新增 `GET /api/chat/models` 每个模型的 `speed` 字段；员工端模型胶囊显示“自动（最快模型）”。
- 新增迁移 `0077_model_speed_index.sql`，按公司 / 角色 / 模型 / 时间读取最近样本。

### 2. 思考档位按模型真实能力配置

- 模型配置的思考档位从固定三档改为可配置列表，每档支持 `ID / 显示名 / 说明 / 上游值 / 输出预算 / 默认档`。
- 支持 `effort` 与 `budget` 两种策略；上游 `reasoning_effort` 显式线值优先，最多 8 档。
- Qwen3.8 默认预设对齐官方 `low / medium / xhigh`；OpenAI 与 budget 预设可在模型弹窗一键套用。
- 服务端把选项 ID 与原生 wire 值同时传入模型调用；关闭思考时 reasoning 归零，控制通道真实生效。
- 员工端思考胶囊和发送请求继续带 `reasoningEffort`，插件仍可消费选项 ID。

### 3. 知识库解析、清洗与切片

- DOCX 解析保留表格在正文中的位置和制度标题层级，不再把表格内容拼成无序段落。
- 清洗阶段保留表格列结构，管理后台预览支持制表符表格。
- 切片阶段按行组切分表格并重复表头，保留标题路径、页码、工作表和行范围。
- 新增纯文本切片工具与专项测试，覆盖表格、长文本和边界输入。
- 用真实 DOCX 验证“解析 → 清洗 → 切片”全流程，表格列和标题层级不再被破坏。

### 4. 权限与角色工具配置

- 角色管理页新增“可用工具”矩阵，保存入口为 `PUT /api/console/roles/:code/tools`。
- 角色页与工具页共用同一份 `tool_role_settings`：角色页提交“该角色应保留的工具”，服务端换算成每个工具的 `all / roles` 白名单。
- 所有角色都勾选时归一为 `all`，避免角色页和工具页显示不一致；平台超管始终拥有全部工具，不能在角色页收回。
- 角色页加载工具目录时复用 `/api/console/tools/access`，只有角色权限、没有工具页权限的成员也能正常打开页签。
- 补充角色工具同步、未知工具、超管保护和控制台接口守卫测试。

### 5. 一键更新与回滚反馈

- 更新状态落盘为 `starting / running / succeeded / rolled_back / failed`，新增 `/api/console/update/result`，刷新或重启后可以恢复上次结果。
- 服务端先写 `starting` 再拉起更新器，确认接管后才关闭当前服务；握手失败不会误关旧服务。
- 增加并发锁，30 分钟内的 `starting / running` 拒绝重复发起；陈旧状态不再永久锁死。
- 修复 `waitPortFree` 把连接超时误判为端口已释放的问题。
- 控制台同时轮询 `/api/health` 与更新结果，回滚或失败立即提示，不再空等 5 分钟。
- 更新范围不覆盖 `docs/`、`demo/`、`EAB使用说明.md`、`EAB企业智能体基座-总体架构方案.md`、`plugins/`、`skills/`、`plans/` 和 `.eab-dev/`。

### 6. 后台与员工端体验

- 模型弹窗的“上下文超限时自动压缩较早历史”等勾选框统一为 16×16 品牌勾选样式，修复被通用输入框样式拉成竖长矩形的问题。
- 勾选态整行浅绿、未勾选静止态白底灰边，补齐 hover 与 focus-visible。
- 模型优先级文案改为“仅在没有实测速度样本时兜底”，用途路由提示同步自动选模口径。
- 静态资源版本更新为 `20261119*`，浏览器刷新即可加载新脚本和样式。

## 数据库迁移

本版新增以下迁移，服务启动时按现有迁移链自动执行：

| 迁移 | 内容 |
|---|---|
| `0077_model_speed_index.sql` | `chat_messages` 按公司 / 角色 / 模型 / 创建时间索引，支撑自动选模读取最近真实样本 |

迁移为增量变更，保留历史数据；真实开发库已完成迁移并通过启动检查。

## 升级提示

- 从 `v2026.11.18` 升级会保留 `.eab-dev` 数据目录；更新器只替换代码，不覆盖运行数据。
- 首次启动会执行 `0077` 迁移，建议升级前做一次 SQLite 快照。
- 自动选模需要真实对话样本；刚升级或新模型没有样本时，仍按工具模型 / 最近成功模型 / `priority` 兜底，发几条消息后自动切到实测最快模型。
- 实测最快模型如果是不带 `tool` 能力的插件模型，复杂工具任务可能不如工具模型稳定；这类任务建议显式选择工具模型。
- 钉钉自动选模复用统一选择器；本版已在网页接口和员工端验证，升级后建议发一条真实钉钉消息确认落库的 `model_id` 与 `meta.timing/tokens`。
- 一键更新仍不覆盖 `docs/` 和用户本地文档，避免升级时冲掉本地编辑。
