# EAB v2026.11.24 发布说明

发布日期：2026-11-24
版本类型：功能版本（多 Agent、记忆 OS、工具治理、图表渠道能力与 UI 全面升级）
发布基线：`main`

## 版本概述

`v2026.11.24` 汇总了 `v2026.11.23.04` 之后的工作，重点补齐企业智能体从“能聊”到“能规划、能协作、能验收、能审计”的底座能力，同时按真实渠道能力收紧图表清单，避免钉钉消息里出现空白或变形图表。

## 多 Agent 协同

- 新增 Agent Plan 对象与版本：计划最多 7 步，支持计划写入、步骤状态推导、跨轮改写和会话计划接口。
- 新增任务图与任务租约：任务依赖、并行执行、失败重试、租约续期和重启恢复都有持久化记录。
- 新增 Agent 团队编队与容量控制：按任务复杂度组织 worker、critic、reviewer，控制台可配置团队上限。
- 新增独立验收员门禁：只认 `review_verdict` 工具结论，正文口头“通过”不算通过；验收失败落库可审计。
- 后台子 Agent 支持完成事件唤醒父 Agent、跨轮续跑、超时收口和失败收尾，父 Agent 只汇总结果，不重复派活。
- 新增任务详情可观测接口与控制台页面，可查看 run、子任务、工具调用、产物和验收结论。

## 记忆 OS 与提示编译

- 新增记忆 OS：长期记忆分层落库、个人偏好记忆、记忆维护、记忆提取运行记录和记忆基准评测。
- 新增 Prompt Compiler v1：系统提示按段编译，每段有独立版本、字符/Token 预算和超限标记，最终提示生成稳定指纹。
- 上下文策略与思考预算合并：推理内容、思考预览和最终答案分开管理，避免半截推理泄漏到正文。
- 执行控制器统一工具轮次、取数门禁、失败恢复和交付前复核。

## 工具治理与工程执行

- 新增工具风险分级与逐次审批：高风险写入、项目命令等按策略审批，审批通过后只允许执行一次。
- 新增 `project.exec` / `project.job`：项目命令在独立 shell 中执行，支持超时、后台任务、输出截断和所有权校验。
- 新增项目命令 OS 沙箱与白名单：未命中白名单直接拒绝，禁止目录穿越。
- 工具失败自动修复、换工具与有限重试，失败原因写回模型而不是直接中断回合。
- 新增产物交接标准化：子 Agent 登记的产物进入完成事件，父 Agent 拿到清单，不需要重读全文。

## 图表渠道能力

- 图表目录成为唯一数据源，新增 `web` / `dingtalk` 渠道过滤：
  - 网页对话保留 17 种完整 SVG 图表；
  - 钉钉消息只保留 7 种能原生保持形状的图表：`pie`、`bar`、`horizontalBar`、`line`、`scatter`、`stackedBar`、`groupedBar`。
- 钉钉不再把环形、雷达、极坐标、热力、瀑布、仪表盘等降级画成柱图/饼图；清单外类型改为明确提示“请到网页端查看”。
- 钉钉 A2UI 正文 24 块预算改为优先保图表，超限只压缩文字和表格，不再把图表压成“图表已省略”。
- Agent 提示词按渠道注入真实图表清单，网页 17 种、钉钉 7 种，模型不会继续输出钉钉画不出的类型。
- `GET /api/charts/catalog?channel=web|dingtalk` 返回对应渠道清单和总数。

## 内容与渠道

- 新增多模态内容工具：图片生成、图片编辑、内容落个人云空间、内容接口下载。
- 钉钉 A2UI 卡片继续支持流式刷新、澄清卡、模型选择卡、工具审批卡、离线汇报和中断回合恢复。
- 新增 A2A 入站/出站端点、能力卡、受限技能白名单和令牌轮换；MCP Server 登记、只读工具同步和工具搜索。
- 新增飞书自检与渠道回调安全校验。

## 部署与工程化

- 新增 Dockerfile、docker-compose、`.dockerignore`、`.env.example` 和 Nginx 部署配置。
- 新增 `eval:agent` / `eval:kb` 基准脚本和 `verify` 发布前校验。
- 新增 SQLite 迁移 `0093`–`0105`，覆盖 Agent Plan、任务图、记忆 OS、模型任务验收、工具审批、记忆分层与基准运行。
- 运行目录 `workspaces/` 纳入忽略规则，避免把用户运行数据提交进仓库。

## UI 与交互

- 全站 UI 体检与改造：对话、工作台、控制台、审批、云空间、设置页统一视觉与交互。
- 新增 UI 动效规范与实验页（`ui-motion-lab`、`ui-overlay-lab`），统一微交互、弹层、确认框和过渡节奏。
- 右侧 Agent 运行台支持子任务状态、产物、日志和预览联动。
