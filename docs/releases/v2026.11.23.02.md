# EAB v2026.11.23.02 发布说明

发布日期：2026-11-23
版本类型：补丁版本（语音播报可控 + 默认音色固定）
发布基线：`main`

## 版本概述

`v2026.11.23.02` 是 `v2026.11.23.01` 的补丁版本，只改语音链路，不动控制台其它功能。两件事：让员工自己选「边生成边播」还是「整段写完再播」，以及把系统默认音色固定成一句明确的描述，避免同一账号每次回答像换了个人。

## 语音播报时机可选

- 设置 → 语音 → 新增「播报时机」一行，两个选项：
  - **边生成边播**（默认）：回答第一句说完就开始出声，适合边看边听。
  - **整段播报**：等回答全部写完，一次性合成再播放，适合先看完整答案再听。
- 选择即时生效并保存到个人档案（`user_voice_profiles.speech_mode`），刷新、换设备后仍保持；非法值会被接口拒绝，不会被写坏。
- 整段模式复用既有收尾逻辑：回答结束时把全文一次性送入合成队列，不会半途插话。

## 默认音色固定描述

- 服务端为系统默认音色补上固定描述：**“清晰、自然、亲切的中文女声，语速平稳，适合办公助手。”**，`GET /api/me/voice` 与设置页的系统默认卡片都显示同一句，不再由前端各写一套。
- 该描述的摘要哈希（`d9852a8769dd3dc8`）与库中已有锚点版本串一致，说明已有员工继续复用原锚点音频、**不会因为改描述而换音**；新用户也按同一句描述生成锚点。
- 试听接口在默认音色且未传描述时自动补这句，保证试听与实际回答同音。

## 数据库

- 新增迁移 `0092_voice_speech_mode.sql`：`user_voice_profiles` 增加 `speech_mode TEXT NOT NULL DEFAULT 'stream'`。迁移只执行一次，旧档案默认沿用边生成边播。
