# EAB v2026.11.23 发布说明

发布日期：2026-11-23
版本类型：语音对话、联网搜索、Agent 协议与平台连接能力版本
发布基线：`main`

## 版本概述

`v2026.11.23` 集中落地网页语音对话、个人音色、内置浏览器与联网搜索、MCP / A2A Agent 协议、天气工具，以及控制台「数据连接」统一接入向导和角色权限页体验优化。

本版新增 8 个数据库迁移：`0084` 至 `0087` 补齐 Agent 协议、MCP、A2A 出站与入站数据表；`0088` 至 `0091` 建立个人语音配置、声音方案与固定参考音频字段。升级时自动执行未应用迁移，不覆盖 `.eab-dev` 运行数据，也不改写既有会话与审批数据。

## 主要变化

### 1. 网页语音对话与个人音色

- 网页工作台保留单一「语音对话」入口：持续录音、前端 VAD 自动断句、一次性 ASR 转写并自动发送，播报期间可开口打断或点按停止。
- 回答按句切分并串行合成，边生成边播放；每个声音方案首次使用时生成固定参考音频和文字稿，后续所有回答、所有句子都复用同一段 `ref_audio + ref_text` 做 Voice Clone，解决“每条回答换一个人”的问题。
- 设置页「我的音色」支持新建、编辑、删除多段声音描述并选择默认方案；网页和钉钉共用同一份配置。
- 助手名字可语音唤醒；管理后台改名后通过 SSE 热更新到已打开的页面，无需刷新。
- 播放器改为 AudioWorklet 连续 PCM 播放：预缓冲、断流重缓冲、块边界 6ms 淡入淡出，避免逐块新建 AudioBufferSourceNode 造成的咔哒声和断流；语音活跃时流式 Markdown 渲染降到约 20fps，降低主线程争抢。
- 真机链路已验证 `voiceEngine=worklet`、`voiceSampleRate=24000`、`voiceUnderruns=0`；主观听感仍需按实际设备复测。

### 2. 内置浏览器与联网搜索

- 新增 `web.fetch`、`web.search`、`browser` 三个内置工具：读取公网网页、联网搜索、无头 Edge/Chrome 打开页面并截图到个人云空间。
- 支持 SearXNG、博查、Tavily、Serper 多 provider；本机 SearXNG 缺失时，`eab start` / `eab server` 会按 Docker、本机 Python 的顺序自动安装并回写控制台配置，也可用 `eab searxng install/status/start/stop` 管理。
- 统一出网代理、`NO_PROXY`、HTTPS CONNECT 隧道、浏览器独立代理、内网访问白名单、SSRF 防护、每用户限流和联网审计。
- 修复 SearXNG 在 `time_range=day/week` 下把 Bing/Baidu 结果全部滤空的问题：时间窗搜索为空时自动去掉时间过滤重试，并在 `hint` 标注“已放宽为不限时间”。
- 修复“今天/今日 + 具体日期”被当成日历关键词的问题：查询 `今天新闻 2026-11-23` 会清洗为 `今天新闻`，真机返回 5 条新闻结果，不再出现 0 条或万年历结果。

### 3. MCP / A2A Agent 团队协议

- 新增 MCP Client Gateway：登记公司级 MCP Server，缓存 `tools/list`，把只读 MCP 工具映射进现有工具目录，统一命名空间、权限、审批、超时、熔断和审计。
- 新增 A2A 出站：登记远端 Agent、缓存 Agent Card、按公司技能白名单委派任务，保存任务映射与产物引用，不复制远端正文和文件。
- 新增 A2A 入站：公司级受限能力卡、共享令牌和入站任务；第一版只暴露 `eab.answer`，外部只能调用公司模型做无工具问答，不读取工作区、知识库、记忆或内部工具。
- 补齐任务上下文、追踪、阶段、暂停原因、产物引用和预算字段；ACP 经评估明确不实施，不改动网页对话主链路。

### 4. 天气工具

- 新增内置只读工具 `weather.now`，基于 Open-Meteo 公开接口，无需 API Key。
- 支持城市/区县名或经纬度，返回当前天气与未来 1–7 天预报；外部 provider 独立适配，后续可替换为和风、高德而不改变工具 id 和权限配置。

### 5. 数据连接与角色权限页

- 控制台「连接与平台 → 数据连接」合并为一张统一连接表，固定分「数据源 / 平台服务」两组：数据源管理 PostgreSQL / MySQL / SQLite / Redis，平台服务管理联网搜索、内置浏览器、内网访问。
- 「＋ 新增连接」统一进入“步骤 1 选择类型 / 步骤 2 配置连接”向导；搜索配置用 6 张服务卡片区分自动 / 关闭 / SearXNG / 博查 / Tavily / Serper，多套地址与 Key 分别保留，“仅保存此配置”不切换生效服务，“设为当前并测试”立即实测。
- 角色权限页优化布局与保存状态：区分未修改、保存中、已保存、保存失败，后台权限和成员访问共用一致的保存反馈，减少重复提交和状态误判。
- 云空间图片预览补充缩放、拖拽与灯箱查看体验。

## 数据库迁移

- `0084_agent_protocol.sql`：任务上下文、追踪、阶段、暂停原因、产物与预算字段。
- `0085_mcp.sql`：MCP Server、工具缓存、熔断与健康状态。
- `0086_a2a.sql`：A2A 远端 Agent、Agent Card 缓存、出站任务映射。
- `0087_a2a_inbound.sql`：A2A 入站能力卡、共享令牌与入站任务。
- `0088_user_voice_profiles.sql`：个人语音开关、内置音色与声音描述。
- `0089_user_voice_presets.sql`：多段声音方案与默认方案。
- `0090_voice_preset_anchors.sql`：声音方案固定参考音频与文字稿。
- `0091_voice_profile_anchors.sql`：系统默认音色固定参考音频与文字稿。

## 升级提示

- 从 `v2026.11.22` 升级会执行 `0084` 至 `0091` 共 8 个迁移，建议升级前备份 SQLite 数据库。
- 旧声音方案没有锚点时会按需惰性生成，首次使用可能多等 5–10 秒；生成后固定复用。
- 搜索 `freshness=day/week` 在本地 SearXNG 的 Bing/Baidu 引擎上不能严格生效，工具会自动放宽并提示结果可能不是最近一天；需要严格时效时建议改用博查 / Tavily 或调整 SearXNG 上游引擎。
- 内置浏览器依赖本机 Edge/Chrome；没有可用浏览器时只影响 `browser`，不影响服务启动和其它工具。
- A2A 入站默认关闭，启用前需生成共享令牌并配置对外地址；第一版只开放 `eab.answer`，不暴露内部工具。
