# EAB v2026.11.18 发布说明

发布日期：2026-11-18
版本类型：功能、体验与稳定性版本
发布基线：`main`

## 版本概述

`v2026.11.18` 完成知识库从“纯文本入库”到“文件解析 → OCR → 清洗 → 切片 → 索引 → 召回测试”的全流程升级；同时落地成员后台访问、页面级动作权限、会话摘要与历史记忆、会话常驻引用、工作区文件夹、钉钉图片发送和 Windows 控制台保护。

本版新增 10 个数据库迁移，均随服务启动自动执行。升级不覆盖 `.eab-dev` 运行数据。

## 主要变化

### 1. 知识库全流程

- 文件上传改为服务端落盘 + `kb_ingest_jobs` 流水线，支持 `pdf / docx / xlsx / pptx / txt / md / csv / json / html / png / jpg / jpeg / webp`。
- 新增 DOCX / XLSX / PPTX / PDF 解析器；PDF 优先读文本层，空文本页渲染成图后走 OCR；图片直接 OCR。
- 新增 `kb.ocr` 多模态 OCR、规则清洗、`kb.clean` 模型清洗；模型清洗按小批次并发执行，单批失败保留原文，整篇失败回退规则清洗。
- 新增统一结构感知切片器，默认约 500 tokens、重叠 80 tokens；表格按行组切并重复表头，保留标题路径、页码、工作表和行范围。
- 管理端新增 Dify 式四步浮层：解析 / 清洗 / 切片 / 索引，一次只展示一步；支持上一步、下一步、点步骤直达、只重跑当前步骤。
- 四步浮层显示预计耗时、实际耗时、全程耗时和清洗剩余时间；大文件清洗按批次写进度，不再长时间无反馈。
- 文档详情新增原始文本、清洗后文本、切片与图片图库；知识库图片通过 `/api/kb/assets/<docId>/<assetId>` 持久渲染。
- 新增 Dify 式召回测试：query、检索模式、topK、阈值、rerank 可调，返回关键词 / 向量 / RRF / rerank 分数与耗时。
- 测试用例支持 CRUD、单次运行和指标统计（Top1、Recall@K、MRR）；支持同一 query 对比已有 embedding 模型。
- 测试记录默认保留 30 天，可在系统设置改为 1–365 天，后台每 6 小时清理过期记录。
- 新增迁移：`0068_kb_pipeline.sql`、`0072_kb_test_retention.sql`、`0074_kb_assets.sql`、`0076_kb_pipeline_estimate.sql`。

### 2. 成员后台访问与页面权限

- 管理端口 `/admin` 改为统一登录页：支持钉钉扫码与账号密码登录；成员登录后只显示被授权的后台页面。
- 控制台权限从“可见 / 管理”拆成 `查看 / 新增 / 编辑 / 删除` 四类动作，支持整页和页内分区（例如渠道页签）分别授权。
- 旧数据 `can_manage=1` 自动回填为三类写动作全开，升级后原有权限不缩水。
- 后台页面注册表统一由服务端维护，前端导航、接口守卫、成员授权和对话页入口使用同一套 page key。
- 成员后台会话落库，支持过期、吊销、成员停用和公司停用校验；平台 token 仍保持全量访问。
- 新增迁移：`0067_console_member_access.sql`、`0070_console_page_actions.sql`、`0073_console_role_page_access.sql`。

### 3. 会话记忆、摘要与常驻引用

- 新增会话滚动摘要：最近消息保留原文，较早消息压缩成结构化摘要；模型不可用时退化为确定性整理。
- 新增个人对话历史全文检索：默认只查当前会话；只有用户明确提到“上次 / 之前 / 历史记录 / 那个对话”时才跨会话召回。
- 新增会话级持久引用：从侧栏拖入的云空间文件、文件夹和对话可作为常驻引用，每轮继续生效，点 `×` 后立即移除。
- 引用按会话保存，新建会话为空，切换会话恢复各自引用；失效对象在发送时跳过，不阻断本轮。
- 每条消息 `meta.attachments` 记录本轮实际使用的引用，历史气泡可追溯。
- 新增迁移：`0069_chat_memory_fts.sql`、`0071_chat_session_summary.sql`、`0075_chat_session_references.sql`。

### 4. Agent 团队与工具恢复

- 子 Agent 名称统一生成，团队进度卡显示真实任务状态、运行时长和当前动作。
- 工具失败后支持自动修复参数、换工具和有限重试；失败信息进入可见进展，不再静默卡住回合。
- 后台子 Agent 完成后唤醒父 Agent 并写汇总；父 Agent 只输出文字、未调用 `agent_task` 时，服务端自动把答复回传给等待中的子 Agent。
- 加强工程任务自检门禁：没有测试通过证据时拦回子 Agent，补跑测试后才允许交付。
- 服务重启后可恢复未完成回合、挂起任务和中断的后台任务；只唤醒本次重启收尾的任务，避免重复派活。
- 新增 `sub-agent-names`、`team-progress`、`agent-verification-gate`、`chat-tool-failure-recovery` 等回归测试。

### 5. 钉钉与飞书渠道

- `workspace.send_dingtalk` 扩展为“发送文件或图片到钉钉”：
  - 支持个人云空间已登记文件；
  - 支持工作区里刚生成、尚未登记 `workspace_files` 的图片；
  - 支持 EAB 知识库图片资产地址。
- 图片优先使用钉钉原生 `sampleImageMsg`，客户端显示为图片气泡；失败降级为文件消息。
- 图片格式限制为 `png / jpg / jpeg / gif / bmp / webp`，单文件上限 20 MB；外部任意 `http(s)` URL 明确拒绝。
- 钉钉入站支持音频消息解析；渠道回合保留幂等键，重启后可恢复未完成卡片和澄清状态。
- 飞书渠道补充无组织架构身份兜底、连接状态与接入自检。

### 6. 云空间与工作区

- 云空间支持文件夹创建、重命名、移动和路径校验；工作区文件按文件夹组织。
- 对话附件可落入个人云空间，消息元数据记录附件来源，前端支持卡片预览和刷新。
- 工作区文件编辑增加版本快照、冲突检测和恢复；保存前同步等待，避免覆盖旧内容。
- 云空间容量与配额接口补齐，容量查询工具可按用户返回已用 / 可用空间。

### 7. 控制台与界面

- 控制台导航改为一级业务域 + 二级横排纯文字导航；插件管理和技能管理作为独立一级项。
- 组织与权限拆为成员管理 / 部门管理 / 角色管理 / 权限审批；连接与平台拆为渠道 / 数据连接 / 在线文档 / 公司设置 / 系统。
- 业务域页面改为单列内容区，插件和技能页保留左侧清单。
- 知识库四步浮层、召回测试双栏工作台、图片图库、文档分页和切片编辑统一视觉；切步骤不再出现嵌套滚动冲突。
- 登录页、启动动画、深色主题和 `prefers-reduced-motion` 路径同步调整。
- 静态资源版本更新到 `20261118*`，部署后不会继续命中旧脚本和样式。

### 8. 稳定性与平台

- Windows 前台启动时自动关闭控制台“快速编辑”模式，避免鼠标点一下终端就把 Node 进程挂起；可用 `EAB_KEEP_QUICK_EDIT=1` 关闭该保护。
- 模型清洗支持关闭思考、超时和中断；上游瞬时 429 / 5xx 在响应未读取时短退避重试。
- 模型空内容、推理内容和清洗重试补齐回归测试；模型故障转移会丢弃半截输出，避免拼接两个模型的回答。
- 控制台任务中心、数据连接、审计镜像、会话镜像和共享缓存继续保留；外部后端不可用时按既定策略降级。
- 架构文档同步知识库全流程、控制台导航、成员后台访问和向量后端口径。

## 升级提示

- 从 `v2026.11.17` 升级会保留 `.eab-dev` 数据目录；更新器只替换代码，不覆盖运行数据。
- 首次启动会执行 `0067`–`0076` 迁移，建议升级前做一次 SQLite 快照。
- 知识库模型清洗和 OCR 依赖已配置的 `kb.clean` / `kb.ocr` 用途路由；未配置时自动回退规则清洗，或进入 `needs_config` 并给出提示。
- 扫描 PDF OCR 依赖 `pdfjs-dist` + `@napi-rs/canvas`；本版已随服务端依赖安装。
- 钉钉图片发送当前走单聊原生图片消息；A2UI 卡片内嵌图片和群聊图片发送尚未实现。
- 外部向量库 Qdrant / pgvector 仍处于规划阶段，本版默认使用本地 SQLite 向量检索，外部不可用时自动降级。
- Windows 控制台保护只影响前台 TTY；后台启动不需要处理。需要保留快速编辑时设置 `EAB_KEEP_QUICK_EDIT=1`。
- 静态资源版本已更新为 `20261118*`，浏览器刷新即可加载新脚本和样式。
