# EAB v2026.11.14 发布说明

发布日期：2026-11-14
版本类型：功能版本
发布基线：`main`，全量 `107` 个测试文件 / `624` 个测试通过，`pnpm typecheck` 通过。

## 版本概述

`v2026.11.14` 是 EAB 企业智能体基座的一次集中功能发布，重点补齐 Agent 工作现场、OnlyOffice 文档全覆盖、技能体系、工具治理、可选后端、异步任务与数据库连接。SQLite 仍是默认主库，PostgreSQL / Redis 为可选增强；不配置这些外部服务时仍可启动和运行。

## 主要变化

### 1. Agent 工作现场与多 Agent

- 新增可见的子 Agent 团队模型：经理 Agent + 团队面板，支持注册、工作、待命、注销的生命周期。
- 右侧工作台支持子 Agent 事件流、运行状态、模型选择与预览文件上下文；预览栏按需显示和隐藏。
- 新增 Agent 回合可续跑 / 挂起恢复、子 Agent 向父 Agent 提问、按任务选择模型、运行数据保留策略与工具直接写入等能力。
- 对话回合增加耗时观测、事件桥接与回合锁；慢工具可转后台任务，避免长时间占用对话。

### 2. OnlyOffice 文档全覆盖

- docx：段落/表格读取、查找、替换、修订读写、批注生命周期、表格删行/删列与合并表安全变更。
- xlsx：插件按编辑器类型注入，工作表读取/定位/替换、保存同步、工作表增删、列宽/行高、legacy 单元格批注 add/list/delete。
- pptx（S13/S14）：补齐 slide 插件注入与 `PRESENTATION` 面板，支持幻灯片页数/形状/文本读取、文本查找与选中、`sN-pM` 段落级替换。
- 当前 OnlyOffice 构建没有 `Api.GoToSlide` / `presentation.GoToSlide`，插件已回退 `ApiSlide.Select()` 完成页跳转；真实编辑器验证了 `1 页 · 2 个形状 · 2 个文本形状` 读取和“第 1 页 · 形状 2”选中。
- 真实 HTTP 验收完成 `office.read_outline` / `office.find` / `office.replace` 的 pptx 闭环；替换只改目标 `slide1.xml`，保留未命中 run 和 `a:rPr`，OnlyOffice 转 PDF 正常渲染。
- 已有的 docx/xlsx 插件面板、保存回写、版本冲突和审计链路保持兼容。

### 3. 技能体系

- 技能与插件同级管理，支持技能目录、角色范围、公司策略、个人安装策略和技能网络来源。
- 安装前校验、安全扫描、高风险工具声明拦截、审批绑定与一次性消费、隔离区复核/删除和审计降级记录。
- 技能正文默认不进入目录摘要，按需通过 `skill_load` 读取；技能声明的工具调用会记录归属。

### 4. 工具治理与容量

- 新增工具按角色可用配置：目录下发和执行入口同时收窄，平台超管保留放行。
- 增加工具 inflight 去重、活动文件绑定、工具指标、直接写入和资源锁；容量与并发限制支持共享缓存。
- 聊天、工作区、插件工具和模型调用的容量边界进一步统一。

### 5. 可选后端与数据库连接

- PostgreSQL 继续承接审计镜像和会话镜像，SQLite 仍是权威主库；`EAB_AUDIT_READ` / `EAB_CHAT_READ` 可切换读取路径，镜像失败自动回退 SQLite。
- Redis 用于钉钉 accessToken、共享容量、锁与模型健康状态等可选增强；未配置时走本地实现。
- 新增控制台“连接与平台 > 数据库”：连接注册、探测、编辑/删除和只读查询；只读查询限制行数并拒绝写语句，查询动作写审计。
- 后端插件支持可选依赖缺失降级；`EAB_BACKENDS_STRICT=1` 时才要求外部服务必须可用。

### 6. 异步任务、定时任务与渠道

- 新增异步任务队列、任务状态和慢工具后台化；控制台任务中心可查看公司任务、状态计数和最近执行。
- 用户自建定时任务按 DSH 定位重做，支持 cron / at / rrule 与任务中心展示。
- 钉钉支持原生长连接、AI 卡片思考/工具过程折叠、手工绑定普通机器人、头像刷新和文件回传；飞书保持独立长连接与自检，不与无关聊天改动耦合。

### 7. 界面与体验

- 对话页重构为可折叠右栏工作台：子 Agent 面板 + 文件预览 + 上下文入口。
- 控制台数据库页、任务中心、技能页、工具角色配置页补齐空态、错误态和窄屏规则。
- 卡片、提示条、加载态和重试路径统一；未安装插件/模型继续保持不可见或不可用。

## 升级方式

1. 从 Release 下载 `EAB-2026.11.14.zip` 源码包；
2. 解压到部署目录，保留原 `EAB_HOME`；
3. 执行 `pnpm install --frozen-lockfile`；
4. 重启服务，等待迁移完成；
5. 打开 `/api/health` 确认 `ok:true`，再检查控制台版本更新页。

桌面安装包、`latest.yml` 和 `.blockmap` 不再发布；已有桌面版请按 `docs/UNINSTALL-REDEPLOY.md` 迁移到 Web / Node 部署。

## 已知边界

- pptx 仍以文本级读取/替换为主，不新增幻灯片、复制版式或插入图片；多页跳转、组合形状和结构编辑还缺更多样本。
- `read_range` 仍只支持 docx；pptx 读取走 `read_outline` / `find`。
- xlsx threaded comments/persons、批注自定义 VML 位置、数字/公式/合并单元格的替换与保存尚未覆盖。
- S15（GUI 兜底白名单）和 S16（版本快照/撤销/冲突策略）尚未开始；当前只保证已验收的文本与结构变更路径。
- MySQL/MariaDB、Redis 未做真实成功路径验收；生产启用前需自备服务并验证网络、权限与 TLS。
