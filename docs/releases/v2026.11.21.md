# EAB v2026.11.21 发布说明

发布日期：2026-11-21
版本类型：上下文预算、附件与文档解析、审批运行时与安全加固版本
发布基线：`main`

## 版本概述

`v2026.11.21` 收口了上下文预算、Office 文档编辑可靠性、聊天附件持久化与文档解析，并把权限审批从“可视化设计器”推进到“运行时真正消费已发布流程拓扑”。

本版同时补齐钉钉回调验签与 `sessionWebhook` 白名单、运行目录 ACL、日志与凭据脱敏，修复钉钉离线汇报身份回退缺陷，并让控制台审批记录页完全改用真实 API。

本版不新增数据库迁移；升级不覆盖 `.eab-dev` 运行数据。

## 主要变化

### 1. 上下文预算与工具收尾

- 工具轮次耗尽后增加一次不带工具的收尾调用，避免回答停在半截或只剩工具调用记录。
- 新增 `capability-route` 能力路由与上下文预算策略，按模型能力、上下文窗口和任务类型选择更合适的处理路径。
- 补充空回复重试、对话引用、记忆召回与系统提示空间测试，减少长会话中上下文挤压导致的丢失。
- 钉钉、飞书与网页对话共用同一套收尾与预算逻辑。

### 2. Office 文档编辑可靠性

- 新增 `office.rewrite` 跨 run 整段重写，修复 Word 文本被拆成多个 run 时无法整体替换的问题。
- 完成真实 docx 替换、整段重写与双文档并行验收，避免并发编辑时互相覆盖。
- 保留修订、批注、表格结构变更与版本冲突拒绝等既有能力。

### 3. 聊天附件持久化与文档解析

- 聊天附件入云空间并写入消息元数据，刷新页面后仍能恢复附件卡片与预览状态。
- 发送时自动解析 PDF、Word（docx）、Excel（xlsx/xlsm）、PPT（pptx）正文，附件卡显示解析页数与失败原因。
- 扫描版 PDF 没有文本层时，配置 `kb.ocr` 视觉模型后自动逐页 OCR；未配置或单页失败时保留可读页并提示原因。
- 新增附件安全检查：扩展名与魔数校验、OOXML 结构检查、EICAR 测试串与压缩炸弹防护。

### 4. 对象存储与附件路由

- 新增对象存储适配，支持把聊天附件与工作区文件写入 S3 兼容存储；未配置时继续使用本地存储。
- 工作区附件上传、预览、下载路由统一走附件存储层，补齐真实接口与浏览器验收。
- 控制台系统状态页展示对象存储配置结果，未配置时明确显示 `objectStorage=null`。

### 5. 权限审批运行时消费流程拓扑

- 已发布的自定义审批流程会按节点顺序生成真实审批步骤；未命中自定义流程时回落到原有经理审批策略链。
- 支持旧 `branches` 嵌套图与显式 `nextIds` 自由连线两种拓扑；条件节点按 `edgeRules` / `edgeLabels` / `else` 选择分支。
- 审批节点支持 `members / manager / company_admin / dept_chain` 来源，支持或签与会签；审批人自动过滤申请人本人并校验公司内审批资格。
- 任一审批节点解析不到可用审批人时直接拒绝提交，不再静默跳过审批节点。
- 内置示例模板不参与运行时匹配，避免覆盖现有权限审批策略链。

### 6. 控制台审批记录接真实 API

- 移除审批记录页 6 条演示数据，改为读取 `GET /api/console/permission-requests?mode=todo|done|all`。
- 页签改为「待处理 / 已结束 / 全部记录」，统计卡与表尾显示真实计数。
- 详情页展示真实申请原因、授权方式、有效期、每个审批节点的审批人、状态、时间与意见。
- 同意/拒绝调用 `POST /api/console/permission-requests/:id/decide`，成功后刷新列表；平台控制台兜底审批按真实审批人落库并写审计。
- 真实浏览器与真实 API 双重验收：重启后仍能查到真实记录与完整审批详情。

### 7. 钉钉回调与离线汇报修复

- 钉钉回调新增 `timestamp + sign` HMAC-SHA256 验签，时间戳限制 ±1 小时，签名比较使用常量时间。
- `sessionWebhook` 只允许钉钉官方域名、443 端口且不带账号信息；回复请求禁止跟随重定向。
- 修复钉钉离线汇报身份回退查询使用不存在的 `created_at` 字段的问题，改为按 `bound_at` 排序；只有组织同步身份时也能正确发送。

### 8. 运行目录与凭据安全

- 启动时收紧运行目录权限：Windows 使用 `Set-Acl` 替换 DACL（当前账号、SYSTEM、Administrators 三组 FullControl），POSIX 使用 `0700/0600`。
- 增加 `.runtime-acl-v1` 标记，避免每次启动重复传播数万文件的 ACL。
- `admin-credentials.txt` 与 `secrets.json` 写入后自动收紧权限；启动日志不再打印控制台密码明文。
- 控制台密码已完成轮换，旧密码失效；历史日志中的旧密码已脱敏。

## 数据库迁移

本版不新增数据库迁移，沿用 `v2026.11.19` 的迁移链。服务启动时只执行尚未应用的历史迁移。

## 升级提示

- 从 `v2026.11.19` 升级会保留 `.eab-dev` 数据目录；更新器只替换代码，不覆盖运行数据。
- 升级前建议做一次 SQLite 快照；本版不改变数据库结构，回滚风险较低。
- 已发布的自定义审批流程会立即参与运行时匹配；升级后建议用一条低危申请验证审批步骤与审批人是否符合预期。
- 扫描 PDF OCR 依赖「模型接入 → 用途路由」中的 `kb.ocr` 视觉模型；未配置时附件仍可预览，但扫描页不会转成文本。
- 对象存储未配置时继续使用本地存储，不影响附件上传与预览；配置 S3 后建议上传一个小文件验证读写与下载。
- 钉钉渠道若使用 HTTP 回调，必须同时配置 `app_secret` 与回调签名；`STREAM` 模式不受影响。
