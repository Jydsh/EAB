# EAB v2026.11.15 发布说明

发布日期：2026-11-15
版本类型：功能版本
发布基线：`main`；发布提交测试 `91` 个文件 / `458` 个用例通过（Release CI 同口径），本地工作区全量 `128` / `732` 通过，`pnpm typecheck` 通过。

## 版本概述

`v2026.11.15` 在 `v2026.11.14` 的基础上，重点补齐数据生命周期、权限审批、渠道回合恢复、Agent 团队持久化、工作区版本与 OnlyOffice 兜底、控制台运维体验和 PDF 预览。SQLite 仍是默认主库；PostgreSQL / Redis 继续作为可选增强，不配置也能完整启动。

## 主要变化

### 1. 数据保留与清理

- 管理端“日志、审计与数据保留”面板新增“项目记录保留天数”，支持日志、审计、Agent 轨迹、项目记录、回收区五套独立策略。
- 项目记录清理覆盖会话与消息、云空间历史版本、工具幂等记录、技能事件、机器人文件回声、Agent 团队消息、团队任务/事件、定时任务运行与事件、异步任务、GUI 兜底和 Office 刷新水位。
- 会话按整段过期处理，不拆散活跃对话；运行中/排队中的任务、未消费事件、审批中记录保留。
- 回收区到期后同时删除物理副本、历史快照、共享、GUI 兜底、Office 刷新水位和文件元数据；路径越界、非普通文件、符号链接一律跳过。
- 外部 PostgreSQL / MySQL / SQLite / Redis 内容仍为只读，EAB 只清理连接同步记录与查询审计；连接配置本身不自动删除。
- `recordRetentionDays` 默认 `0`（永久保留），设置 `7–3650` 天后生效。

### 2. 多级权限审批

- 新增角色申请、按 scope 配置审批链、逐级审批、超时和公司管理员兜底。
- 只授角色、不授 scope；最终通过写角色授权与有效期，读侧过滤过期角色。
- 控制台新增“权限审批”页面，支持可申请角色和审批策略；员工端走申请与审批流程。
- 钉钉审批卡片持久化 `outTrackId`，服务重启后仍能更新原卡并收口。

### 3. 渠道回合与钉钉卡片恢复

- 新增渠道“进行中回合”持久化：原始入站 payload、会话、消息 ID、卡片 `outTrackId` 和 Agent 回合幂等键落库。
- 服务重启后可恢复或明确收口钉钉 Stream 回合，避免已 ACK 消息丢失或重复插入用户消息。
- 钉钉答题卡状态落库，重启后旧卡的上一题/下一题/提交仍可用。
- 钉钉 A2UI 卡片流式正文不再追加光标或 loading GIF，减少卡片抖动。

### 4. Agent 团队与模型分配

- 子 Agent 团队从进程内存迁移到数据库，支持跨轮次、跨进程重启继续派活。
- 新增后台任务、父 Agent 事件收件箱、任务幂等键与团队消息持久化。
- 父 Agent 可优先用 SystemOne 决策端点按任务内容选择子 Agent 模型；失败自动回退能力匹配。
- 保留 Agent 运行/步骤轨迹、挂起恢复和父子取消级联。

### 5. 工作区、Office 与 PDF

- 新增云空间文件历史版本快照、版本列表和恢复接口；快照文件不计入配额。
- 新增 OnlyOffice 原生 GUI 兜底状态机和 Office 刷新水位，防止旧编辑器回调覆盖新版本。
- 工作台接入 PDF.js 预览；新增 `/vendor/pdfjs/*` 静态资源路由。
- PDF.js 要求 Node.js `>=22.13.0`，根 `engines` 与 README 已同步。

### 6. 控制台与运维体验

- 新增登录后启动动画：全局默认 + 公司覆盖，支持代码版/电影片头、跳过和刷新轻启动；片源支持 Range 请求。
- 新增控制台品牌与主题配置、管理端/员工端标签与图标预览。
- 新增服务器目录选择器与只读目录浏览，区分本机/远程控制台交互方式。
- 存储位置支持在线切换 SQLite 连接，保存后不重启；旧连接转只读，避免迟到写落旧库。
- `eab server` 在 PATH 缺少 pnpm 时回退 tsx 直启，适配任务计划/隐藏窗口启动。
- 管理端保留面板新增项目记录、数据连接查询审计和回收区元数据统计。

## 数据库迁移

本版本新增迁移 `0056`–`0062`，启动时自动执行：

- `0056_workspace_versions.sql`：工作区历史版本
- `0057_channel_turns.sql`：渠道进行中回合
- `0058_workspace_gui_fallbacks.sql`：OnlyOffice GUI 兜底
- `0059_workspace_office_refresh_guards.sql`：Office 刷新水位
- `0060_agent_team.sql`：Agent 团队持久化
- `0061_permission_approvals.sql`：多级权限审批
- `0062_dingtalk_clarify_cards.sql`：钉钉答题卡状态

迁移均为在线新增表/索引或可空列，不删除既有业务数据。

## 升级说明

1. 升级前备份 `.eab-dev/eab.db` 与运行数据；密钥、控制台口令不在普通备份中，请单独保管。
2. Node.js 需 `>=22.13.0`；PDF 预览依赖该版本起点。
3. 升级后检查“系统与运维 → 日志、审计与数据保留”：项目记录默认永久保留，按需设置 `7–3650` 天。
4. 外部数据库连接内容不会被保留任务删除；如需清理外部库业务数据，请使用数据库自身策略。
5. 回收区元数据删除后，单文件级追溯依赖清理汇总审计 `ops.settings.retention.run`。
