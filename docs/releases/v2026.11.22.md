# EAB v2026.11.22 发布说明

发布日期：2026-11-22
版本类型：审批协作、命令行更新与文件恢复修复版本
发布基线：`main`

## 版本概述

`v2026.11.22` 完成「指定角色」会签、审批进度与催办、流程设计器实人预览和部门层级约束，并把 `eab update` 收口为可直接升级、降级和重装的命令。

本版同时修复权限审批接口的页面可见性守卫、聊天文件引用恢复为文件夹、历史附件类型识别，以及会签步骤顺序不稳定等问题。

本版新增两个数据库迁移：`0082_permission_approval_group.sql` 放开同一审批步骤的多审批人约束；`0083_permission_approval_progress.sql` 增加审批节点快照字段和催办记录表。

## 主要变化

### 1. `eab update` 命令收口

- `eab update` 直接升级到 GitHub 最新 Release，不再需要 `--apply`。
- `eab update <版本>` 直接升级或降级到指定版本；`--check` 只查看目标版本，不安装。
- 同版本默认不重装，必须显式加 `--force`。
- 保留 `--apply`、`--version=版本` 作为旧写法兼容。
- 更新前继续停服务、备份代码与运行数据，失败自动回滚；不覆盖 `.eab-dev` 运行数据。

### 2. 指定角色会签

- 审批节点新增第五种审批人来源「指定角色」，保存 `roleCode / roleName`，审批方式固定为会签。
- 提交时解析角色内全部在职且具备 `approval:decide` 的成员，排除申请人本人，同一节点同一 `step_no` 同时激活。
- 全部会签成员同意后才进入下一节点，任一成员拒绝则整单拒绝。
- 角色选择弹窗列出全部角色；只有具备审批决定权限且有在职成员的角色可选，其余灰显并标明原因。
- 钉钉审批卡支持会签成员并发展示、会签进度、通过后等待同节点成员，以及整单拒绝提示。

### 3. 审批进度、催办与运行时稳定性

- 审批步骤保存来源节点 id、节点标题、节点方式和审批角色，员工端按真实节点聚合展示审批流程。
- 新增节点催办：申请人或同节点审批人可催办当前待处理人，钉钉发送独立催办提醒，带冷却时间和催办次数记录。
- 会签节点支持重发钉钉审批卡，卡片按审批人分别投递。
- 同毫秒批量写入的步骤统一按 `rowid` 排序，修复会签步骤展示、同步骤读取、下一级激活和催办目标顺序偶发错乱。

### 4. 流程设计器审批节点

- 「直属上级 / 部门负责人链」支持节点级审批级数，上限按当前公司真实组织层级收敛，超过上限会立即回退并提示。
- 实人预览逐级列出直属部门、上级部门和公司负责人；无负责人、无审批权限、申请人本人等被跳过的层级会显示具体原因，不再只显示最后一个可审批人。
- 审批人规则说明收进 `?` 角标，避免属性面板重复堆叠说明文字。
- 结束节点只允许连接到抄送节点；抄送节点作为流程末端不再被要求继续出线。
- 修复旧模板节点缺失 `source` 时实人预览报“来源不支持”的问题，运行时与预览统一按部门负责人链处理。

### 5. 权限与文件修复

- 权限审批接口按页面可见权限放行，避免无权限页面直接调用审批接口。
- 聊天中的文件夹引用恢复为文件夹卡片，不再误判成普通文件。
- 历史附件按真实内容纠正类型，图片、文档和文件夹引用在刷新后保持一致。

## 数据库迁移

- `0082_permission_approval_group.sql`：去掉 `(request_id, step_no)` 唯一索引，新增 `(request_id, step_no, approver_user_id)` 唯一索引，支持同一节点多人会签。
- `0083_permission_approval_progress.sql`：为审批步骤增加 `node_id / node_title / node_mode / approver_role_code / approver_role_name`，新增 `permission_approval_urges` 催办记录表及索引。
- 升级时自动执行未应用的迁移；不会覆盖 `.eab-dev` 运行数据。

## 升级提示

- 从 `v2026.11.21` 升级会执行 `0082`、`0083` 两个迁移，建议升级前备份 SQLite 数据库。
- 已发布的自定义审批流程继续生效；升级后建议用一条低危申请验证部门负责人链和「指定角色」会签。
- 指定角色会签要求角色具备 `approval:decide` 且有在职成员；未满足条件的角色在流程设计器中不可选。
- 会签节点需要所有成员处理完毕才进入下一节点；任一拒绝会结束整单。
- 催办依赖审批人已绑定钉钉；未绑定钉钉时页面会提示未送达。
