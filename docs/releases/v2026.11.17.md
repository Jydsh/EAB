# EAB v2026.11.17 发布说明

发布日期：2026-11-17
版本类型：功能与稳定性版本
发布基线：`main`

## 版本概述

`v2026.11.17` 把权限申请从“申请角色”升级为“申请权限点”，补齐云空间上传的真实进度与失败提示，并集中落地项目命令执行、插件/技能自开发、大工具结果分页、渠道模型切换和 Agent 后台协作等能力。默认日志级别同时改为 `warn`，正常请求不再刷满日志。

## 主要变化

### 1. 权限申请改为权限点

- 员工端只展示当前身份缺少、且可申请的非管理权限点；已有权限不再重复出现。
- 申请记录新增 `request_type`，新申请写 `scope` 类型并保存本次选择的 `scopes_json`；历史 `role` 类型申请继续按原路径处理。
- 审批通过只写 `permission_scope_grants`，不写 `user_roles`，也不授予申请时用作身份锚点的角色。
- 临时授权支持到期时间和撤销；`actorFor()` 读取未过期、未撤销的授权，到期后读侧立即失效。
- 多级审批按每个 scope 的策略合并：取最长审批级数、最短超时；公司管理员兜底、固定审批人冲突和 `dept_chain` / `fixed_users` 混用会被拒绝。
- 钉钉审批卡片按 scope / role 分支展示，历史角色申请仍可继续流转。
- 新增迁移 `0063_permission_scope_grants.sql`，服务启动时按现有迁移链自动执行。

### 2. 云空间上传修复与进度反馈

- 修复 `#ws-input` 的 `FileList` 实时集合问题：先复制文件列表再清空 input，文件不会再被静默丢掉。
- 上传改为 XHR 队列：每个文件独立显示 `pending / preparing / uploading / done / error`，并用 `upload.onprogress` 展示真实进度。
- 支持多文件顺序上传；失败时解析后端 `message` / `hint`，401 回到登录流程。
- 超过 50 MB 的文件不再静默 `alert` 后跳过，改为在上传面板内明确提示“超过 50 MB，未上传”。
- 上传期间禁用上传按钮，结束后恢复并刷新云空间列表；面板增加 `aria-live`，兼容深色主题和 `prefers-reduced-motion`。
- 后端上传接口未改，仍走 `POST /api/workspace/files`。

### 3. 项目命令执行

- 新增本地项目执行器：每次调用使用全新 shell，`cwd` 锁定在员工工作区内，拒绝路径穿越。
- 默认 120 秒、最多 600 秒；超时杀进程树；stdout / stderr 各保留 64 KB 尾部，完整输出交给批次层落盘。
- 支持后台任务，用于 `npm install`、`dev server` 等长命令；每个用户最多 8 个后台任务，任务默认保留 30 分钟。
- 新增 `project.exec` / `project.job` 工具接入，前台返回退出码、stdout、stderr，后台可按 job id 读取或终止。
- 该能力默认关闭，需设置 `EAB_PROJECT_EXEC=1` 后重启。当前是本地执行器，`enforcement=none`，不做文件隔离；共享部署不要把它当作安全边界。
- 修复全量测试并行时 PowerShell 冷启动超过默认 5 秒造成的偶发超时：相关用例追加 `20_000ms` 超时，单独跑与全量跑均通过。

### 4. 插件与技能自开发

- `plugin_dev`：在员工云空间 `.eab-plugins/<id>` 生成 DSH UI 插件骨架，改完代码后直接安装为个人插件，安装即热生效，不需要浏览器上传目录或重启服务；返回 `/plugin-kernel.html` 预览地址。
- `skill_dev`：在 `.eab-skills/<id>` 生成 L0 纯提示词技能骨架，改写 `SKILL.md` 后再次安装即为热更新；默认只允许提示词与只读工具，仍走静态安全扫描和安装审批。
- 插件 host 增加依赖安装、配置热重载和实例隔离；单个插件依赖安装失败只记录在对应实例，不阻断其他插件。
- 插件页轮询版本指纹，重装后自动刷新；技能详情可从工作台预览地址查看真实启用状态。

### 5. 大工具结果与工作区文本

- 工具返回的大记录数组或长文本会先落成本地批次，模型只收到批次 id、总行数和首尾片段，避免撑爆上下文。
- 新增 `batch_read` 分页读取和 `batch_analyze` 服务端分批分析；批次只允许所属公司/员工读取，默认保留 24 小时。
- 新增工作区文本按行读取与代码检索：默认/单次最多 2000 行、单次输出 50 KB，超过上限返回 `nextOffset`，由模型继续读而不是整文件塞入上下文。
- 前端增加批次结果展示，长结果不再只能看一段截断文本。

### 6. 渠道与 Agent 协作

- 钉钉/飞书父 Agent 新增 `switch_chat_model`：支持切换当前会话模型、恢复自动选择和列出可用模型；切换从下一条消息生效，避免误称本条回复已由新模型生成。
- 后台子 Agent 完成后可唤醒父 Agent 并写出汇总；父 Agent 只输出文字、未显式调用 `agent_task` 时，服务端会把答复回传给等待中的子 Agent。
- 继续补齐 Agent 运行检查点、挂起恢复、任务复活和团队消息持久化；服务重启后可恢复未完成回合。
- 钉钉澄清卡片支持网页作答同步、状态持久化和重启后恢复；渠道回合保留幂等键，降低重复插入用户消息的风险。

### 7. 日志与界面

- 服务端默认日志级别从 `info` 改为 `warn`：正常 2xx 请求不再逐条打印，4xx / 5xx、启动和异常日志仍保留。排查时可用 `EAB_LOG_LEVEL=info` 临时恢复。
- 工作台修复内容宽度：个人插件内容铺满可用区域，不再只占左侧约 464px。
- 修复权限面板、父 Agent 消息、上传状态等交互的布局与状态恢复；静态资源 query 统一更新为 `20261117a`，部署后不会继续命中旧脚本/样式。
- `EAB使用说明.md` 同步补充日志默认级别和临时恢复方式。

## 数据库迁移

本版本新增 `0063_permission_scope_grants.sql`：

- `permission_requests` 增加 `request_type`，默认 `role`，兼容历史数据。
- 新增 `permission_scope_grants`，记录 `request_id`、`scope`、`expires_at`、`revoked_at` 和授权人。
- 迁移随服务启动自动执行；真实库已完成迁移，历史角色申请不受影响。

## 升级提示

- 从 `v2026.11.16` 升级会保留 `.eab-dev` 数据目录；更新器只替换代码，不覆盖运行数据。
- 项目命令执行默认关闭；需要时设置 `EAB_PROJECT_EXEC=1` 后重启。该执行器不做文件隔离，仅建议在可信的单机/个人工作区使用。
- 默认日志级别改为 `warn` 后，正常请求不再出现在日志里；需要排查时临时设置 `EAB_LOG_LEVEL=info`。
- 静态资源版本已更新为 `20261117a`，浏览器刷新即可加载新脚本和样式。
