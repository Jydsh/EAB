# EAB 全站 UI 体检与改造路线

- 日期：2026-11-24
- 范围：员工工作台（对话 / 工作台 / 浮层）、管理后台（21 个页面）、登录门口
- 对照规范：`docs/EAB-高级UI动效规范-2026-11-24.md`
- 对照技能：`eab-ui-motion`（`SKILL.md`、`references/patterns.md`、`references/overlays.md`）
- 原则：先查清，再改造；一次只改一批；每批都在真实页面验收

## 1. 需求理解

这不是“给所有页面加动画”，而是把 EAB 的界面重新统一成一套可解释的工作界面：

1. **每个页面先回答“我在哪、现在什么状态、下一步做什么”。**
2. **每个操作先选对容器。** 必须处理的用 Modal / Alert Dialog；边看边操作的用 Drawer；行内确认用 Popconfirm；成功提示用 Toast。
3. **动效只做解释层。** 状态变化、层级关系、空间关系、注意力落点，各对应一种明确效果；不靠堆特效制造“高级感”。
4. **先改高频、低风险、全局收益大的地方。** 不做一次性大重构，不把所有卡片统一上浮、倾斜或流光。
5. **每批都能停。** 一批改完、验收完，再决定下一批；任何一批都不影响登录、权限、数据读写和关键业务流。

一句话验收：**页面更清楚、操作更顺手、状态更可信；动画减少而不是增多。**

  - 动效验收：`http://127.0.0.1:8787/ui-motion-lab.html`

### 2.2 六个审计维度

| 维度 | 要检查什么 | 不合格的表现 |
|---|---|---|
| 信息层级 | 页面第一眼先看到什么；标题、指标、主体、操作是否成组 | 页面直接从表格开始；主 CTA 与危险操作混在一起 |
| 状态语言 | 运行、等待、成功、失败、空、无权限是否都有稳定表达 | 只靠颜色；错误自动消失；空状态像加载失败 |
| 浮层选型 | 是否用对 Modal / Drawer / Toast / Popconfirm / Dropdown | 筛选、详情、成功提示都塞进 Modal |
| 动效语义 | 每个动画能否一句话说明解释了什么 | 全站卡片上浮、表格文字解码、循环光效过多 |
| 密度与可读性 | 表格行高、字号、截断、操作列是否可扫读 | 长描述挤成一段；操作按钮重复且无分组 |
| 无障碍与响应式 | 键盘焦点、Esc、reduced-motion、窄屏溢出 | 浮层无焦点锁；手机信息只在 Tooltip；表格横向溢出 |

## 4. 改造顺序

### P0 · 全局底盘与概览样板

- 后台每次换页有 160ms 的“页面到达”反馈，不隐藏首屏、不阻塞点击。
- 后台长页的面板统一使用 `data-motion="reveal"`：首屏自动跳过，滚动进入才出现。
- 概览的 KPI 数字使用 Count Up；快捷入口使用 Hover Lift。
- 先证明这套规则不会破坏表格、表单、权限和浮层。

### P1 · 高频工作区

- 员工工作台：工作台页面层次、插件 / 技能列表状态、Agent 团队运行态。
- 后台：成员、部门、角色、知识库、模型、渠道、数据连接、插件。
- 只做“结构与状态”的动效，不动表格正文。

### P2 · 配置与运营页

- 权限审批、权限矩阵、工具、在线文档、公司设置、用量、额度、审计、任务、审批、技能。
- 重点补：详情 Drawer、行内确认、真实指标、空态与失败态。
- 这一步开始减少重复按钮和无效信息，不只是加动效。

### P3 · 系统页与边缘场景

- 系统运行、队列、Agent、任务、更新；语音对话；登录门口。
- 只在真实状态变化处使用 Notification / Border Beam / Spring；其余保持安静。
- 最后做 375 / 768 / 1280 窄屏与 reduced-motion 全量走查。

## 5. 每页改造的输出格式

每个页面改动前，先写清楚这一句；写不出来就不改：

```text
场景：<页面/组件> 在 <状态> 时。
浮层：<类型>，负责 <阻断 / 边看边操作 / 轻提示 / 解释 / 命令>。
主效果：<16 种之一>，负责 <解释什么>。
辅助效果：<最多 1–2 个>，负责 <解释什么>。
参数：<时长> / <缓动> / <位移或透明度>。
边界：<哪里不用>；减少动态效果时 <降级方式>。
验收：<在哪个真实页面看什么>。
```

## 6. 验收矩阵

| 检查项 | 通过标准 |
|---|---|
| 不遮挡 | 首屏内容、表格、表单、错误提示不被动画隐藏 |
| 不拦截 | 动画期间按钮仍可点击；快速重复点击不会锁界面 |
| 浮层 | Modal / Drawer / Toast / Popconfirm 选型正确；Esc、焦点、滚动锁完整 |
| 降级 | `prefers-reduced-motion: reduce` 下无循环动画，信息完整 |
| 键盘 | Tab 焦点可见；浮层关闭后焦点回到触发按钮 |
| 响应式 | 375 / 768 / 1280 无横向溢出、无遮挡、无抖动 |
| 性能 | 只改 `transform` / `opacity`；一屏不超过 3 个循环动画 |
| 真实页面 | 每批至少在一个真实业务页验收，不只看示例页 |

## 7. 当前不做

- 不做全站统一卡片上浮、3D 倾斜、跑马灯。
- 不给聊天正文、表格行、错误提示加文字解码 / 打字机。
- 不为“高级感”重做信息架构；先解决可读性和状态表达。
- 不在一个页面同时放 Spotlight、Beam、Stagger、Count Up 四种以上效果。
- 不把 `ui-motion-lab.html` / `ui-overlay-lab.html` 当产品页面入口。
