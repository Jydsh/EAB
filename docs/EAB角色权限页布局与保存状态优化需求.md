# EAB 角色权限页布局与保存状态优化需求

## 背景

角色管理「角色权限」页签内容较长时，页面底部的「保存角色 / 删除角色」操作栏必须滚动到卡片最底部才能看到；同时角色详情头和页签会随内容一起滚出视口。用户在处理中间权限项时无法随时保存，操作路径不顺畅。

## 目标

1. 角色详情头、页签和底部操作栏保持可见，只有中间的角色配置与权限内容滚动。
2. 「保存角色」「保存后台权限」在提交期间显示明确的加载状态，阻止重复提交。
3. 不改变角色权限的保存接口、校验规则和最终数据结果。

## 行为合同

### 布局

- 进入角色详情后，角色详情头与「角色权限 / 后台权限 / 可用工具 / 角色成员」页签固定在角色工作台顶部。
- 「角色权限」页签内的角色名、数据范围、存储配额和权限分组位于独立滚动区域；滚动该区域时，详情头、页签和底部操作栏不移动。
- 底部「保存角色 / 删除角色」操作栏固定在角色工作台底部，首屏即可看到，不要求先滚到内容末尾。
- 后台权限、可用工具和角色成员页签采用同一结构：页签头固定，中间内容滚动；带底部操作栏的页签保持操作栏可见。
- 窄屏（宽度不超过 1120px）继续使用自然页面流，不强制固定高度，避免内容被压缩到不可读。

### 保存状态

- 点击「保存角色」后，先执行现有必填与配额校验；校验不通过时不进入加载状态，只在状态区显示错误。
- 校验通过后，按钮立即变为「保存中…」，带旋转指示，设置 `disabled` 和 `aria-busy="true"`，并保持按钮宽度稳定。
- 加载期间再次点击「保存角色」不发起第二次请求。
- 保存成功后显示成功提示并刷新角色数据，按钮随新界面恢复；保存失败时按钮恢复为「保存角色」、解除禁用，并在状态区显示失败原因。
- 状态文案使用 `role="status"` / `aria-live="polite"`，让读屏用户能获知保存进度和结果。

### 后台权限保存状态

- 点击「保存后台权限」后，若后台页面目录未加载，不进入加载状态，只在状态区提示刷新后重试。
- 正常提交时按钮变为「保存中…」，带旋转指示，设置 `disabled` 和 `aria-busy="true"`，普通态与保存态宽度一致。
- 加载期间再次点击不发起第二次请求。
- 保存成功后显示成功提示并更新页面计数，按钮恢复为「保存后台权限」；失败时同样恢复按钮并显示失败原因。
- 状态文案使用 `role="status"` / `aria-live="polite"`。

## 验收

- 1299×952 视口下，角色详情头、页签和底部操作栏在首屏可见。
- 滚动中间权限区域到底部，详情头与操作栏位置不变。
- 保存请求进行中，按钮文案为「保存中…」、禁用且不可重复点击；请求结束后恢复。
- 现有权限保存、配额校验和角色刷新行为不变。

## 实现落点

- `packages/server/public/app.js`
  - 角色详情根容器使用 `role-workbench-editor`。
  - 四个页签各自提供 `.role-pane-body` 作为唯一滚动区，权限页签的 `form-grid + scope-groups` 已包进滚动体。
  - 切换页签时把当前 `.role-pane-body` 的 `scrollTop` 归零。
  - 「保存角色」使用 `roleSavePending` 防重入；`setRoleSaveBusy()` 负责 `disabled`、`aria-busy`、`is-loading` 和「保存中…」文案。
  - 保存成功刷新角色数据；失败恢复按钮并保留失败原因。
  - 「保存后台权限」使用 `roleConsoleSavePending` 防重入；`setRoleConsoleSaveBusy()` 负责同样的加载态，成功更新计数，失败恢复。
- `packages/server/public/app.css`
  - 详情头与页签固定，`.role-pane-body` 独立滚动，`.role-pane-footer` 固定在 pane 底部。
  - 覆盖权限树、工具表、成员列表原有的嵌套 `max-height`，避免双滚动条。
  - `.btn.is-loading` 提供旋转指示，并在 `prefers-reduced-motion` 下停用动画。
  - 「保存角色」固定 100px 宽；「保存后台权限」固定 112px 宽，普通态与「保存中…」态宽度一致。
  - `≤1120px` 退回自然页面流。
- `packages/server/public/index.html`
  - 管理端资源版本更新为 `20261122d`。

## 验收记录

- 1299×952 视口实测：工作台固定高度 702px，主区不滚动；权限滚动体 `clientHeight=385`、`scrollHeight=945`，滚到底部后详情头与底部操作栏坐标不变。
- 「保存角色」保存中实测：按钮文案「保存中…」、`disabled=true`、`aria-busy="true"`、带旋转指示；普通态与保存态宽度均为 100px；连续点击 3 次只发出 1 次保存请求。
- 失败实测：模拟保存接口返回 500 后，按钮恢复为「保存角色」、解除禁用并显示失败原因。
- 「保存后台权限」保存中实测：按钮文案「保存中…」、`disabled=true`、`aria-busy="true"`、带旋转指示；普通态与保存态宽度均为 112px；连续点击 3 次只发出 1 次请求。
- 「保存后台权限」失败实测：普通员工角色因后端禁止修改自己所属角色而返回错误，按钮恢复、解除禁用并显示原因；审计员角色保存成功，按钮恢复并显示「已保存」。
- 四个页签实测均只有一个滚动区，底部操作栏可见；角色成员页签无底部操作栏，内容滚动到工作台底部。
- `pnpm typecheck` 通过。全量 `pnpm test` 中 1180/1181 通过，唯一失败为 `eab update` 用例访问 GitHub 超时，单独重跑 1.08s 通过，与本轮改动无关。
